# Turtle Mountain Cyber Awareness Website

Open `index.html` in a browser. No build process is required.

Files:
- `index.html`: page content and sections
- `styles.css`: black, purple and pink responsive theme
- `script.js`: mobile menu and interactive checklist
- `assets/brochure-qr.png`: QR graphic cropped from the supplied brochure

To publish, upload the folder to Netlify, GitHub Pages or another static hosting provider. Verify the QR code destination and contact details before publication. The original brochure's sector pie chart was omitted because its source/date and precise meaning were not supplied.
